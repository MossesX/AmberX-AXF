# Memory system decisions

- **Oct 18 2026:** rules, guidelines, decisions and memory must be active when he works in Claude Code from the mosh terminal on the VPS. First kept in the AmberX-AXF repo (`memory/`).
- **Oct 18 2026:** moved onto axHub (`memory/<git repo name>/`), read and saved by every session on any device; writes free, deletes need approval; repos kept a read-only mirror. Later the same day: a `general` folder for rules that apply everywhere.
- **Oct 18 2026 (current, claude-fs@1):** every new and existing project has `_memory/` with `memory/`, `instructions/`, `rules/` (plus `decisions/`, `docs/`, `sessions/`, `inbox/`) and `shared/`. A project's `_memory/` syncs with `/Claude/projects/<project>/_memory/`; `shared/` syncs with `/Claude/_memory/shared/` and holds everything that applies to all projects, in the same sections. `/Claude` is a real folder on the VPS. Project data lives in `/Claude/projects/<project>/data/` and syncs with the project's original paths (listed in `_memory/data.json`). Everything in `_memory/` is committed, `shared/` included. When a file changed in two places, sync holds it and asks him. Old locations (`memory/` mirrors, `/opt/axhub/persist`, hub `memory/<repo>`) were moved in. Built on Opus. axHub decisions #71-#76.
