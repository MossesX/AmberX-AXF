# axf-devtools

Developer console for any AXF app: kernel status (modules, extension points filled/empty, placeholders), feature-flag playground, action and event logs (recorded through `ActionBus.intercept` + `EventBus.history`), asset inspector/validator, the build-engine client (`HttpBuildEngineClient` against the VPS driver, `NotImplementedBuildEngine` otherwise) and the `axf dev` hot reloader. Contributes the `devtools` route and a Developer settings group.

**Plugin Manager** (`PluginManagerModule` + `PluginManagerScreen`, Oct 20 2026): every module and installed plugin with its health, dependencies (what it needs, who provides it, who needs it) and clashes from the kernel's `PluginInventoryEngine` (plugin-inventory@1, same engine as the web console's Plugin Manager); views Cards / Table / Detail / Dependencies in layouts Studio / Mission control / Terminal / Catalog; route `plugin-manager`, dialog `plugin-manager.window`, actions `plugin-manager.open[:<id>]` / `.window`, a link in the default context menu, and a Plugin Manager sub-tab under Settings → Plugins; choices are the same settings keys as the web plugin and are re-read on resume (UI-editor rule). Compose previews `PluginManager_<layout>_<view>` are planned for the CI screenshot job (Android screenshots pending CI).
