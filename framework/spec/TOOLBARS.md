# Toolbar library

Generated by `node framework/cli/asset-library.mjs` from its toolbar seeds — edit the seeds, not this file
(`--check` in CI fails when they drift). 25 starter toolbars in `framework/assets/toolbar/`; any app picks one in
Settings → Appearance → Toolbar, a design package or an interface.

## What makes a toolbar dynamic

- **Live groups** — a group with `provider: "<id>"` gets its buttons from the application menu’s provider registry
  (`rt.registerAppMenuProvider`), after any fixed items, capped by `max` (1–24, default 8) and reloaded shortly
  after the app’s state changes. Built-in providers:

  - `views` — every page the app registers (`nav:<view>`)
  - `nav` — the active navigation menu’s items
  - `settings` — every settings tab, plugins’ included (`settings.open:<tab>`)
  - `windows` — every open floating window (`windows.restore:<id>`)
  - `dialogs` — every registered dialog (`dialog:<id>`)
  - `chrome` — show/hide toggles for every bar and menu, drawn pressed while shown

  Apps and plugins register more (the console adds `console.pending`, `console.plugins`, …); a group whose provider
  isn’t registered and has no fixed items isn’t drawn.
- **Badges** — `items[].badge: "<counter>"` shows a runtime counter (`rt.setBadge`) on the button, hidden at 0.
- **Toggles** — `items[].checked: "setting:<key>" | "counter:<name>" | "slot:<type>" | "hidden:<type>"` draws the
  button pressed (`aria-pressed`) while the binding is on (same bindings as the application menu).
- **Widgets** — `widgets: [{type, id, at: start|end, order}]` places clock, status, counter, progress, logo,
  label, avatar, theme switch, spacer, divider, search bar … widgets; status/counter/progress follow runtime counters.
- **Live search** — `search: { live: true, placeholder, maxResults, kinds }` finds pages, actions, settings,
  dialogs, assets, windows and words as you type (Ctrl/Cmd+K or /).
- **Look** — `density` compact/regular/roomy, `surface` flat/raised/glass, `divider`, `collapsible` (fold, per device).

Every button is gated by UAC (`requires`), and a host app (embed@1) can take or lock an action. Android twin of
live groups and toggles: deferred (port on hold, `framework/spec/PORTING.md`).

## Each toolbar

### Enterprise Command (`enterprise-command`)

File, edit and look commands with labels, a live search and the account and connection status at the end.

- **file**: New (`file.new`); Open (`file.open`); Save (`file.save`); Export… (`file.export`)
- **edit**: Undo (`edit.undo`); Redo (`edit.redo`)
- **app**: Alerts (`alerts.open`, badge alerts.unread); Settings (`app.settings`)

### Live Pages (`live-pages`)

Every page of the app as a button, straight from the views provider, so new pages appear by themselves.

- **Pages**: Go home (`nav:home`) + live `views` up to 10

### Navigator Strip (`navigator-strip`)

The active navigation menu drawn as a labelled strip; swapping the nav menu changes the strip too.

- **Navigation**: live `nav` up to 12

### Window Switcher (`window-switcher`)

One button per open floating window to bring it back, beside the window and layout commands.

- **Open windows**: live `windows` up to 8
- **layout**: Next layout (`swap:layout:next`); Show or hide navigation (`slot.hide:nav-menu:toggle`, slot:nav-menu)

### Chrome Toggles (`chrome-toggles`)

Pressed-state toggles for every bar and menu (chrome provider), plus the spacing choices.

- **Bars and menus**: live `chrome` up to 8
- **spacing**: Super tight spacing (`spacing:tight`); Compact spacing (`spacing:compact`); Regular spacing (`spacing:regular`)

### Settings Jump (`settings-jump`)

A tab for every settings page, from the settings provider; plugin settings join as they install.

- **Settings pages**: live `settings` up to 10

### Dialog Launcher (`dialog-launcher`)

Every dialog the app and its plugins register, one tap away, with a search limited to dialogs and actions.

- **Dialogs**: live `dialogs` up to 8

### Developer Ops (`developer-ops`)

Build, deploy and the dev console with the alerts badge, a build progress bar, AI status and a 24 h clock.

- **run**: Build (`run.build`); Deploy (`run.deploy`)
- **tools**: Dev console (`dev.console`); Alerts (`alerts.open`, badge alerts.unread)

### Ops Monitor (`ops-monitor`)

A status board: connection, unread alerts, build progress and the clock, with settings and help at the start.

- **app**: Settings (`app.settings`); Documentation (`help.docs`)

### Editor Classic (`editor-classic`)

The classic editing row: new, open, save, export, undo, redo and the clipboard.

- **file**: New (`file.new`); Open (`file.open`); Save (`file.save`); Export… (`file.export`)
- **history**: Undo (`edit.undo`); Redo (`edit.redo`)
- **clipboard**: Cut (`edit.cut`); Copy (`edit.copy`); Paste (`edit.paste`); Delete (`edit.delete`)

### Appearance Studio (`appearance-studio`)

Step design packages and every theme, roll or reset the look, with the day and night switch at the end.

- **package**: Next design package (`design.package:next`)
- **themes**: Next colour theme (`swap:color-theme:next`); Next style theme (`swap:style-theme:next`); Next layout (`swap:layout:next`)
- **roll**: Randomize the look (`assets.random`); Reset the look (`assets.reset`); Appearance settings… (`settings.open:appearance`)

### Minimal Glass (`minimal-glass`)

A centred frosted strip with search, alerts and settings only.

- **app**: Alerts (`alerts.open`, badge alerts.unread); Settings (`app.settings`)

### Touch Dock (`touch-dock`)

Roomy labelled buttons spread across the width, sized for thumbs: home, pages, alerts and settings.

- **go**: Go home (`nav:home`)
- **Pages**: live `views` up to 3
- **app**: Alerts (`alerts.open`, badge alerts.unread); Settings (`app.settings`)

### Reader Bar (`reader-bar`)

Quiet labels for reading apps: spacing choices and the documentation link.

- **spacing**: Compact spacing (`spacing:compact`); Regular spacing (`spacing:regular`)
- **help**: Documentation (`help.docs`)

### Portal Header (`portal-header`)

Wordmark at the start, the navigation as labels, and the account avatar at the end.

- **Navigation**: live `nav` up to 6

### Approvals Desk (`approvals-desk`)

Waiting approvals and unread alerts as counters, with undo, redo and save for the reviewer.

- **review**: Undo (`edit.undo`); Redo (`edit.redo`); Save (`file.save`)
- **inbox**: Alerts (`alerts.open`, badge alerts.unread)

### Data Grid Tools (`data-grid-tools`)

Flat, dense tools for grids: new row, copy, delete, export, and the pages provider for quick jumps.

- **rows**: New (`file.new`); Copy (`edit.copy`); Delete (`edit.delete`); Export… (`file.export`)
- **Pages**: live `views` up to 6

### Brand Bar (`brand-bar`)

Logo mark, the app version label and the day and night switch around a centred search.

- No buttons: widgets only.

### Kiosk Lite (`kiosk-lite`)

A clock and a single help button; nothing that changes the app.

- **help**: Documentation (`help.docs`)

### Search First (`search-first`)

A wide search-bar widget up front that finds anything, with the chrome toggles beside it.

- **Bars and menus**: live `chrome` up to 4

### Quick Create (`quick-create`)

New and open, followed by the first four dialogs the app registers (wizards, importers…).

- **file**: New (`file.new`); Open (`file.open`)
- **Create**: live `dialogs` up to 4

### Status Strip (`status-strip`)

Widgets only: AI and connection status, build progress, unread alerts and the clock.

- No buttons: widgets only.

### Power User (`power-user`)

Eleven icon commands, the pages provider and the bar toggles, folding away when not needed.

- **file**: New (`file.new`); Open (`file.open`); Save (`file.save`)
- **edit**: Undo (`edit.undo`); Redo (`edit.redo`); Cut (`edit.cut`); Copy (`edit.copy`); Paste (`edit.paste`)
- **app**: Alerts (`alerts.open`, badge alerts.unread); Settings (`app.settings`); Keyboard shortcuts (`view.shortcuts`)
- **Pages**: live `views` up to 6
- **Bars**: live `chrome` up to 4

### Review Flow (`review-flow`)

Undo, redo and save with the open windows provider so reviewers jump between compared items.

- **history**: Undo (`edit.undo`); Redo (`edit.redo`); Save (`file.save`)
- **Open windows**: live `windows` up to 6
- **inbox**: Alerts (`alerts.open`, badge alerts.unread)

### AmberX Signature (`amberx-signature`)

The AmberX house toolbar: live pages, a live search, the day and night switch and the account, on glass; the brand draws its own mark here.

- **Pages**: Go home (`nav:home`) + live `views` up to 6
- **app**: Settings (`app.settings`)
