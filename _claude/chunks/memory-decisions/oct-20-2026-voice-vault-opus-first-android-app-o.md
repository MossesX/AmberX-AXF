## Dev Console

- **Oct 20 2026 — Voice Vault (Opus), first Android app on AXF that defines libraries.** Brett asked for a voice-activated password app: say the unlock code, then a key (store / retrieve password); store asks the site then the password and fills editable fields with Save; retrieve asks the site, shows it in a top banner, confirm (tap or voice) copies the password; settings let him record his own triggers or use default lists. He chose to build it **on AmberX AXF** and to make the second step a **setting** (voice code only / + fingerprint / + PIN). Lives in `apps/voicevault` (project `voice-vault`, repo name reserved, not created). Broke out two framework libraries: `lib-voice` (speech, prompts, voice commands with user triggers) and `lib-lock` (biometric/PIN second step); `AxfActivity` became a `FragmentActivity`. No Fable rebuild (security work is Opus by the model rule).
