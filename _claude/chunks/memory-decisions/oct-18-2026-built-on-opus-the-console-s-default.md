## Framework

- Oct 18 2026 (built on Opus): the console's default toolbar is the new **Console Search** toolbar asset: a live search box (dropdown on every keystroke) over pages, actions, settings, dialogs, assets, open windows and words on pages; picking a result brings it onto the screen. Any toolbar asset can turn it on with `data.search.live`.
