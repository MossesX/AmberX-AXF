## Oct 20 2026 — App catalog on axHub (app-catalog@1)

- Oct 20 2026 (refined twice the same night): **all settings and shared data of Brett's developer apps come from the axHub data server.** Developer apps = the Dev Console (web + its Android app, apps/console), Build Pilot (web + its Android app when it exists), axHub's own app, the AXHub Android app and future dev apps (not every app built on AXF). **Voice Vault is left out** (Oct 21 2026): it's a personal password vault that stays offline with its own settings and must run when the VPS is down. The theme is *data*: the theme selection (names/ids per appearance slot, spacing, hidden slots…) is a settings document stored on axHub's data server (shared data, axhub-projects@1), never fetched from the axHub web app; every developer app, axHub's own app and the Android apps included, reads its theme settings and its other settings from that server. A theme change in any console tab writes the document and every app follows it live. **When axHub is down, developer apps don't run:** they show a "waiting for axHub" screen until the hub is back (no local fallback, no default theme).
