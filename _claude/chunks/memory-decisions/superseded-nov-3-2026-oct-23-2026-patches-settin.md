## Oct 21 2026 — the axHub web app is an AXF developer app (Opus)

- *[superseded Nov 3 2026]* **Oct 23 2026 — Patches settings tab group + banner hide switches (Brett).** An app running inside Patches never greys out its settings: settings that don't apply inside the host are removed, not greyed (this replaces the greyed Settings → Plugins of Oct 22). Patches' settings interface is a tab group: a tab for Patches itself and one for every app, plugin or anything else in a Patches tab that has the settings UI; the settings hook in any hosted app opens Patches settings with the tab it came from in focus. Patches' context menu gets a **Settings** submenu with one entry per settings tab. Banners: plugin@1 gains a field declaring the plugin includes a banner; every banner's settings carry **Hide** (hides it, its plugin keeps running and logging), under it an indented **Hide all banners** (tooltip lists every installed banner it hides), and a **timer** checkbox enabling a two-digit minutes field: a hide lasts that many minutes, then the banner shows again. All three are one state shown the same in every interface; the last change wins. Built on Opus (pending `patches-settings-banner-hide`), Fable rebuild parked (`patches-settings-banner-hide-fable`).
