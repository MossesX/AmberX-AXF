## Sessions

- **Every Claude session works as the agent Brett assigns (Nov 3 2026, Brett):** every Claude session (voice and chat Amber, Claude Code, headless builds; any machine) calls `claude_session_start` first ({client: voice|chat|code|headless, summary}; console MCP, or `axf claude-session start`) and works as the crew agent it answers: it introduces itself by that agent's name, follows the agent's persona / voice notes, sets `AXF_AGENT` to it, and books its cost, time and commits on that agent's card with `claude_session_book` (`final: true` at the end). With *Ask me every session* on (default) Brett picks the agent in the console pop-up (or approves the default on axHub); until he answers the session is the default agent, and `claude_session_agent` tells it when that changes. Headless builds keep their brief's named agent unless *Ask for headless too* is on. Never answer the pick yourself. Settings: Settings → Plugins → Claude sessions; `apps/console-web/plugins/claude-session/README.md`. <!-- axf-plugin:claude-session -->
