## Before building anything

- **Screenshots go in a named group, and Brett names it (Nov 1 2026, Brett: "When Claude sends shots for him, it must ask him for a name"):** UI Review → Screenshots files every screenshot in exactly one named, timestamped group, so he can find them. Before any Claude session (any surface: voice, chat, Claude Code, claude.ai) sends screenshots for Brett, it **asks him for the group name** (a card, the default first, made from what was shot + now in his time: `Breakroom check - Oct 31 8:20 PM`) and sends them with `--group "<that name>"` (`axf shot <files> --name "…" --app … --screen … --group "…"`, or `group` in `POST /api/plugins/ui-review/shots`). **Headless sessions** can't ask: they name the group after their build (`--group "<build id> - <Mon D h:mm AM/PM>"`). Same name the same day = the same group; no name = `<session/source> - <YYYY-MM-DD HH:mm>`, which is only a fallback. <!-- axf-plugin:ui-review -->
