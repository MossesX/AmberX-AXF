## Before building anything

- **Models: the build orchestrator decides, per step (Oct 27 2026, Brett: "Forget previous model select rules"; replaces "Pick the model first" and "Ask every time").** Every build is broken into steps of 30 min or less in the Build orchestrator (`_claude/builds/orchestrator.json`, console → Builds → Build orchestrator, `apps/console-web/plugins/build-orchestrator/orchestrator.mjs`), each step pinned to **Fable** (cross-port contracts, kernel/engine internals, schema + migration design, heavy refactors, work that changes how GUIs work across apps) or **Opus** (everything else). Don't ask for a model per build. **Only an upgrade needs approval (Nov 3 2026, see "Model upgrades need Brett"):** a switch to a lower model passes by itself; a switch to a higher model waits for Brett's own approval (his console click or an axHub approval), never the session's. Save tokens: one session, no new session or sub-agent unless a step needs it, briefs carry only the current phase. You can't switch models yourself: at a switch, stop and give Brett the next phase's brief (`orchestrator.mjs brief <id>`) to run on that model. <!-- axf-plugin:build-orchestrator -->
