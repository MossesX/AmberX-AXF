## Before building anything

- **Everything in UI Review has a name, a timestamp and one schema (Nov 1 2026, Brett: "No exceptions"):** every item in UI Review — the approve / reject queue and Screenshots, from any source (Claude chat or voice, Claude Code, headless builds, agents, the console, plugins, manual uploads, Watch live) — is a `ui-review-item@1` (`framework/core/ui-review-schema.mjs`, `framework/schemas/ui-review.json`): a human name, a group (`ui-review-group@1`), an ISO `createdAt`, kind, source, sender, app, screen, viewport, files, and a status on review items. Every intake (API, `review.mjs`, `shot.mjs`, `rebuild-shots --submit`, `ui-review@1.submit`, the Upload button) refuses anything missing with the field named; the only defaults are `createdAt` = now and, when nobody can ask Brett, the automatic group. Claude asks Brett for the group name (card, default first) before sending anything on his behalf. <!-- axf-plugin:ui-review -->
