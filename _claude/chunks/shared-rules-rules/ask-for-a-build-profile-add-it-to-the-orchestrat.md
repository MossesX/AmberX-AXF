## Before building anything

- **Ask for a build profile, add it to the orchestrator first (Oct 27 2026, Brett; replaces the Oct 22 "goes on the Build manager list" rule):** "Anytime something is being built or edited or removed, anything that will change features and function, prompt for what build profile to send to orchestrator. Always add to orchestrator and have orchestrator populate the other lists like pending and queued." Whenever any session (any machine, any surface) is about to build, edit or remove anything that changes features or function, ask Brett (card) which build profile to send to the Build orchestrator, then add it to the orchestrator (`_claude/builds/orchestrator.json`, `orchestrator.mjs act …`, console → Builds → Build orchestrator) before starting. Never add it to the pending list, build queue or other lists directly; the orchestrator populates those. Merge into an existing orchestrator build instead of adding a duplicate; when it's finished, mark it complete there with a note naming the branch/PR (or failed/broken). Questions, docs and rules-only edits that change no feature or function need no profile. <!-- axf-plugin:build-orchestrator -->
