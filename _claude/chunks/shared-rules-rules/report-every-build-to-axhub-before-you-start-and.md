## Before building anything

- **Report every build to axHub before you start, and keep it live (Oct 21 2026, Brett):** any session anywhere (Claude Code on the VPS or any computer, headless runs, subagents, claude.ai chats, console launches) that is about to build, edit, remove or fix something first records it in the Build manager's log on axHub (`change-log@1`, `/projects/amberx-axf/_data/changes/<YYYY>/<MM>/<id>.json`, all projects): title, what it belongs to (`buildRef`), model, **time estimate (minutes) and cost estimate (USD)**, `status: running`, surface, host, branch and the folders it will touch (`areas`). Then update it as you work (each step, `lastSeenAt` heartbeat at least every few minutes, `doing`), and finish it with the result, actual time, and actual tokens/cost when the session can count them (else the estimate stays, `costEstimated: true`). **Claude Code:** the hooks do most of it (`node <AmberX-AXF checkout>/apps/console-web/plugins/codebase-changes/changes.mjs hooks install`, once per machine, all projects); add the estimate with `changes.mjs update <id> --ref … --model … --estimate-min N --areas "…"`. **claude.ai (no shell):** write the entry JSON with `axhub.memory_write` (project `amberx-axf`, area `data`, path `changes/<YYYY>/<MM>/<id>.json`) and rewrite it on every step. Exact shape: `_claude/memory/docs/build-reporting.md` in AmberX-AXF. Don't start work the Build manager shows as running in another session, and don't touch the folders a running entry lists.  <!-- axf-plugin:codebase-changes -->
