## Before building anything

- **Every UI change goes to UI Review (Oct 30 2026, Brett):** every build that adds or changes UI (an app, a screen or page, a settings interface, a dialog or popup, a menu or toolbar, a banner or card, anything visible) submits its desktop + phone screenshots to the console's **UI Review** plugin for his approval before the PR is called ready: `node <AmberX-AXF checkout>/apps/console-web/plugins/ui-review/review.mjs submit --kind <app|screen|settings|dialog|menu|banner|other|any new kind> --name "…" --app <app> --screen <screen> --group "…" --shots a.png,b.png --branch <b> --pr <n> --console` (or `rebuild-shots.mjs … --submit <kind>`, or `POST /api/plugins/ui-review/submit`). Say in the PR that it is waiting there. A PR whose UI review is waiting, has changes asked or is rejected is held (capability `ui-review@1`, `review.mjs state --pr <n> --exit-code`). <!-- axf-plugin:ui-review -->
