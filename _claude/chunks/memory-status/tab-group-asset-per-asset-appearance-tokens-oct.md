## Status (as of Oct 21 2026)

- **Tab group asset + per-asset appearance tokens (Oct 24 2026, Opus; Fable rebuild parked as `appearance-asset-tokens-fable`; web only, Android deferred):** new optional hideable asset type **`tab-group`** (style underline/pills/boxed/segmented/plain, align, position, density, overflow, showIcons, divider; starters `underline` (default = the old look), `pills`, `boxed`, `segmented`, `plain-centered`; `tabGroupStyle` in `components.ts`, CSS keyed off `data-fx-tabs*`; hidden = only each row's active tab). Settings → Appearance → **Assets** is now one collapsible card per slot (its picker) holding one collapsible card per asset of that type; with more than one asset, **Apply settings to all** (ticked by default) leaves only the first editable and greys the rest, unticked = every asset editable (values copied). Each asset gets **35 extra tokens** (`framework/schemas/customize.json`, asset-customize@1: font size/weight/family, letter spacing, case, italic, line height, alignment, text/background/border colour, opacity, glass, item alignment, location (pinned top/bottom, chrome only), width, padding, item padding, gap, corners, border width, shadow, icon set, icon size/colour, show icons, entrance animation + speed + easing, hover behaviour + colour, pointer, click behaviour + colour, focus ring) and an **icon set from a list of 100** (`framework/schemas/icon-sets.json`: 20 styles × 5 weights restyling the framework icons). Engine `core/engines/customize.ts` (setting `axf.custom.<type>` = `{all, shared, byId}`, values of the slot's active asset compile to one `<style id="axf-custom">` via `rt.customSheet()`; theme tokens only). `Container` gained `collapsible`/`defaultOpen`. CI `npx -y tsx framework/spec/check-customize.mts` (131). Not screenshot-verified.
