## Status (as of Oct 21 2026)

- **App catalog on axHub — app-catalog@1 (Oct 20 2026, built on Opus; axHub decision #86):** every Android app built with the framework gets a download link on the hub. CI (`android.yml`) builds every app `framework/cli/app-bundle.mjs list --android` finds, stamps `versionCode` from the run number (`AXF_BUILD_NUMBER`; template + apps), signs with a stable debug key when the `ANDROID_DEBUG_KEYSTORE` secret (base64) is set, and uploads artifact `app-apks` (`app-bundle@1`: `apps.json` + one APK per app, 30 days). The console (`server/app_catalog.py`, thread every 10 min, `AXF_APP_CATALOG_EVERY`) takes the latest green run on main, checks sha256 and names, files `apks/<project>/<project>-<version>-b<build>.apk` (last 3 builds per app) and `catalog.json` in `/projects/_shared/_data/app-catalog` (`AXF_APP_CATALOG` overrides); routes `GET /api/app-catalog`, `POST /api/app-catalog/sync` (console token). Needs `GITHUB_TOKEN` with Actions: read. The hub serves it at `https://axhub.amberxai.com/apps` (admins, or users with `apps.download`). Console App tabs has an **axHub** tab (`/apps`; framing needs `AXHUB_APPS_FRAME_ANCESTORS=https://console.amberxai.com` on the hub); inside Patches the hub is Patches' own tab instead. The AXHub phone app has an **Apps** tab that downloads through Android's download manager. Test `server/test_app_catalog.py` (15).
