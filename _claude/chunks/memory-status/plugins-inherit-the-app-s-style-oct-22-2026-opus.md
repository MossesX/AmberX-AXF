## Status (as of Oct 21 2026)

- **Plugins inherit the app's style (Oct 22 2026, Opus; rule in `_claude/rules/RULES.md`):** every button, tab, chip and toggle in every console plugin and framework library is now a framework control, so changing the app's button asset, style theme or spacing restyles the plugins too. Framework additions (web): `<Button size="sm">` (`fx-btn--sm`) + tones `success` / `quiet`, `<IconButton icon label>`, `<Segmented>` (`fx-seg`, `fx-seg__opt`), tappable `button.fx-chip` (`is-on`), page tabs `fx-tab` (window tabs scoped to `.fx-tabgroup__bar .fx-tab`), and `data-fx-row` for a whole row/card you tap (reset under `:where()` so the plugin's layout wins). 155 hand-styled controls in 18 plugins + settings/alerts/mcp libs converted; restyling CSS removed. CI `node framework/cli/check-controls.mjs` (every `<button>` is a framework control or `data-fx-row`; a plugin class on a control may only lay it out). Spec: `framework/spec/THEMING.md`. Not screenshot-verified (the console waits for axHub in the build sandbox). Android twin deferred.
