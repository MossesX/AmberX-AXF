## Status (as of Oct 21 2026)

- **Studio harvest: six libraries with configurable parts (Oct 22 2026, Opus; Fable review parked in `walkthrough-studio-fable`):** **library@1 parts** = features inside a library an app includes or leaves out and configures one by one (`parts: [{id, label, description, default, requires, params}]`; installed config `libraries.<key>.parts`; `core/library.ts` `includedParts`/`withRequired`/`partNeededBy`/`partErrors`/`resolvePartConfig`/`partOn`/`partParams` = CLI `resolveParts` (`axf install … --parts a,b --part a.key=v`); catalog parser keeps `parts`; fixture `spec/fixtures/library-parts.json`, `check-library-parts.mts` in CI; Kotlin deferred). Harvested from Walkthrough Studio into `framework/libs`: **dnd** (pointer drag-and-drop, touch grip, markers, ghost, pop-up trash), **tree** (TreeView + TreeSearch), **datagrid** (categorized DataGrid, hideable/sortable columns, expandable rows, drag), **workspace** (pane areas, splitters, layouts, floating panes, unlimited docked/floating toolbars, ToolbarCustomizer, `axf.ws` action + menus), **recorder** (useRecorder, CaptureLayer, CursorLayer, Replay, eventsToCues), **docstore** (device + axHub data server chunked under 64 KB, IndexedDB blobs). Walkthrough Studio runs on all six (manifest `libraries.*`). Build Pilot shows each library's parts as features with their own settings in the Customize… sheet (`src/pilot/parts.ts`, sent as `params.parts`). Doc `framework/libs/README.md`, `_claude/memory/docs/walkthrough-studio.md`.
