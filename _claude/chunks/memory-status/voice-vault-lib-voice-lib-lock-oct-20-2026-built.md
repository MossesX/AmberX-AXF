## Status (as of Oct 21 2026)

- **Voice Vault + lib-voice + lib-lock (Oct 20 2026, built on Opus):** `apps/voicevault` (`voice-vault`, `android-compose` + `voice` boilerplate): voice password vault. Say the unlock code (salted PBKDF2 hash in the secure store; typed fallback; lockout), then the second step from Settings → Unlock (voice only / + fingerprint / + PIN). "Store password" → site → password (on-device recognizer when available) → editable fields → Save; "retrieve password" → site (fuzzy, "gmail dot com" = gmail.com) → top banner → confirm (voice or tap) copies it as sensitive and clears it after 30 s. Vault = AES-GCM with a Keystore key in `noBackupFilesDir`, entries in memory only while unlocked, auto-lock on leaving/idle, `FLAG_SECURE`, settings/lists only while unlocked. New framework libraries: **`lib-voice`** (`AxfVoice`: `SpeechInput`, `Speaker`, `VoiceCommands` with defaults + user-recorded/typed triggers persisted in KV `axf.voice.triggers`, `PhraseMatcher` pure Kotlin, `VoiceTriggersScreen` route `voice-triggers`, Voice settings group) and **`lib-lock`** (`AppLock`: biometric `BIOMETRIC_STRONG` / PIN via `PinHasher` + `Lockout`, auto-lock delay, `PinPrompt`, `PinSetupScreen` route `lock-pin`, fills `android.biometric`). `AxfActivity` is now a `FragmentActivity` (fragment-ktx 1.8.5 in the catalog). CI: `:lib-voice:testDebugUnitTest :lib-lock:testDebugUnitTest` + Voice Vault APK artifact `voicevault-debug.apk`. **Always listening (Oct 21 2026, Opus; app code only):** a **global trigger** (voice command `vault.wake`, defaults “hey vault” / “voice vault” / “open vault”, set in Settings → Global trigger and commands = the Voice triggers screen) heard by `background/WakeService` (foreground service, type microphone, ongoing “Voice Vault is listening — only for …” notification with Stop) while the app isn't on screen, screen off included; it pauses while the app is open (`VaultSession.inApp`), uses the on-device recognizer only (no on-device recognizer = it doesn't run), matches only the trigger (partial results, so it reacts mid-sentence), then opens the app at the unlock step: by itself with *Display over other apps*, else a full-screen alert, else an alert to tap (`WakeListener.delivery`); it wakes the screen and asks Android to unlock the phone, never shows over the lock screen. Started from `MainActivity.onResume` (Android only starts a microphone service from the foreground; not restarted after a kill). Setting **Listen in the background** (default on) + **Let it pop open**. Voice screen: **You can say** card (exactly what each step listens for, every phrase: `VaultSession.listeningFor`) and **In the background** card (listener state, the trigger phrases, what happens when heard, buttons for blocked permissions).
