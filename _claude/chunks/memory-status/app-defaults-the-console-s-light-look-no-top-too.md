## Status (as of Oct 21 2026)

- **App defaults: the console's light look, no top toolbar (Oct 20 2026, Fable):** `framework/defaults.json` → `color-theme: arctic-daylight`, `style-theme: glass-orbit`; new **`framework/app-defaults.json`** (`app-defaults@1`) holds the non-slot defaults: `hidden: ["toolbar"]`. **`manifest.hidden`** (both ports: `AxfManifest.hidden`, TS `AxfManifest.hidden`) = chrome slots hidden by default; the hide engine takes it as the default layer under the user's overrides (`hiddenSlots(overrides, defaults)` = Kotlin `HideEngine.hiddenSlots(types, overrides, defaults)`, `defaultHidden(...)`; `setSlotHidden` drops the override when it equals the default, so Settings → Appearance can still show the toolbar; Kotlin's `<key>:hide` store is now a `{type: bool}` object, the old array still reads). Fixtures `hide.json` gained `defaults` cases. `axf init` writes `hidden` (request `hidden` overrides the app defaults; `validate` checks it names hideable types). Existing apps switched: voicevault, axhub-android, console (Android), demo (demo still runs an older baked framework, so its toolbar shows until a re-bake); the web console hides its toolbar **and** side navigation since Oct 21 2026 (`hidden: [toolbar, nav-menu]`), because its application menu reaches everything (see Console application menu); its alerts bell is on the banner (`alerts-bell` plugin, Oct 21 2026).
