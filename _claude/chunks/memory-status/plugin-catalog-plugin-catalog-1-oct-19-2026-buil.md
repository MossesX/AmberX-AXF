## Status (as of Oct 21 2026)

- **Plugin catalog — plugin-catalog@1 (Oct 19 2026, built on Opus):** plugins any of Brett's apps can install, kept on axHub at `/projects/_shared/_data/plugin-catalog` (`catalog.json` index + `packages/<kind>/<folder>/<version>.json` = `plugin-package@1`, files base64 with a content hash; the console mounts `/projects`, axHub serves the same folder via `axhub.memory_*` project `shared` area `data`; `AXF_PLUGIN_CATALOG` overrides, `off` = none). Engine `framework/cli/plugin-catalog.mjs` (`where|list|show|pack|publish [--console URL]|publish-package|package|install|remove`, `--json`): kinds are an open registry (`console` = plugin@1, any safe file; `pilot` = pilot-plugin@1, web files only); checks on pack, publish, read and install: folder names, plain relative paths (no `..`, dot-files, symlinks, node_modules/dist), never secret-looking files, 600 files / 2 MB / 8 MB caps, hash checked against the index on every read, a published version never changes (raise it), an id can't move folders; install never overwrites another plugin's folder or a symlink and swaps the folder in atomically. **Console install** = unpack into `apps/console-web/plugins/<folder>`, run its lifecycle install, and commit just that folder to GitHub (`publishAddition` in `plugin-lifecycle.mjs`, same temp-worktree push as uninstall `--publish`; needs `GITHUB_TOKEN`), so the 5-minute update rebuilds the console with it. Console routes (console token on every method, never on MCP): `GET /api/plugin-catalog[?kind=]` (installed/clash marks for console plugins), `GET /api/plugin-catalog/package?kind=&folder=[&version=]` (Build Pilot reads packages here server to server), `POST /api/plugin-catalog/install {folder, update?, version?, confirm: folder}`, `/publish {folder}` or `{package}`, `/remove {kind, folder, confirm}`. UI: Plugin Manager → **Install** view (install/update with typed confirm, take out, publish any console plugin; Build Pilot entries listed). Build Pilot installs pilot plugins from its own Plugins page (Build-Pilot repo). The console server now skips dot folders when loading plugins (half-installed folders). CI: `framework/spec/check-plugin-catalog.mjs` (27), `server/test_plugin_catalog.py` (19).
