## Status (as of Oct 21 2026)

- **Shared data lives on the hub (Oct 18 2026, built on Opus; moved to /projects the same day):** the root manifest's `data.shared` (pending list, plan + media, build queue, catalog `status.json`, `libraries.json`, `project-rules.json`, `tracker.json`) is read and written in `/projects/amberx-axf/_data/<same path as in the repo>`. Resolver: `framework/cli/persist.mjs` (`dataPath(rel)`, used by every CLI module, engine-rpc, serve, sync-data; `_persist_root()` in `server/main.py`): `AXF_DATA_DIR` (exact folder, `off` = repo), else legacy `AXF_PERSIST_DIR`, else `/projects/<name>/_data` when `/projects` exists (`AXHUB_PROJECTS_DIR` overrides), else `/opt/axhub/persist/<name>` while it still exists, else the repo. A file missing there is seeded from the repo copy. `deploy/install-console.sh` finds the `axhub-projects` volume (`AXHUB_PROJECTS_VOLUME` overrides), stops the old console, copies the old `/opt/axhub/persist/amberx-axf` in once (no overwrite; marker only after a clean copy), then renames the old folder to `amberx-axf.moved-to-projects` so no second copy diverges, sets uid 1000/setgid group-writable, and mounts the volume at `/projects` in the console (umask 002); without the volume it keeps the legacy folder. It also moves back anything the reverted claude-fs@1 installer had put in `/Claude`. Repo copies are synced snapshots: `claude-sync sync` or `persist.mjs pull`, then commit.
