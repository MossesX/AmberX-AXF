## Status (as of Oct 21 2026)

- **Build profiles — build-profiles@1 (Oct 27 2026, Opus):** a build profile is one complete set of work data: pending list, plan (+ media), build queue, catalog `status.json`, `tracker.json` and the Build orchestrator's tracker. **Main framework** (`main-framework`, base) keeps every original path; **Refactor** (`refactor`, the saved pick since Oct 27 2026; started empty, then took today's refactor/upgrade items from main: pending `arch-foundation`, `enterprise-branding`, `interface-roller`, `design-package-fable`, `apply-all-levels-fable` + five finished ones, orchestrator builds `arch-foundation`, `enterprise-branding`, `interface-roller`, `design-package`; main keeps its copies with a note) and any later profile live under `framework/plan/profiles/<id>/<same path>` (hub shared data) and `_claude/builds/profiles/<id>/orchestrator.json` (repo). Registry `framework/plan/profiles.json` (shared data, never profiled) holds the saved pick for every device; `AXF_BUILD_PROFILE=<id>` overrides it for one process. Resolution is central: `persist.mjs` → `dataPath(rel)` (profiled list `PROFILED`, open; `baseDataPath` for unprofiled files, `orchestratorPath()`), so every CLI, engine-rpc, MCP tool and console view follows the active profile with no other change; a new profile's files start empty (or copied with `--copy-from`), never seeded from main. Plan rebuilds import seed + catalog only in profiles with `catalog: true` (main: on, new: off). CLI `node framework/cli/profiles.mjs [list|current|select <id>|create "<name>" [--copy-from <id>] [--catalog] [--select]|update|remove <id> --confirm <id>|where]` (remove = off the list, data kept). Console server: `build_profiles.py` (Python mirror, `cx.data_path(rel)` / `cx.build_profile()` for plugins; pending alerts, plan media and the build manager read through it), `GET/POST /api/profiles` (writes need the console token); test `server/test_build_profiles.py` (30, Node = Python). Not profiled: libraries index, project rules, sessions, the Codebase changes log (global history), THREADS.md, the activity plugin's holds (main's pending ids), the claude.ai Pending Builds page (mirrors main).
