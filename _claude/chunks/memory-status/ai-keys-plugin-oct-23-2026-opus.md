## Status (as of Oct 21 2026)

- **AI keys plugin (Oct 23 2026, Opus):** `apps/console-web/plugins/ai-keys` (`ai.amberx.axf.console.ai-keys`). Dialog `ai-keys` (action `ai-keys.open`, right-click menu, Plugins › AI keys…, Settings → Plugins → AI keys): stores several Anthropic API keys (sk-ant-api…) and Claude subscription tokens (sk-ant-oat…, `claude setup-token`), kind detected from the prefix; each is tested before it's saved (API key: model list; token: one tiny Claude Code CLI turn) and an invalid one is refused; re-test, rename, remove; pick the active key per kind (or none). Keys only in `.axf-console/plugins/ai-keys/keys.json` (0600), browsers see name + last 4. Provides `axf.ai-keys@1` (`active_key(kind)`); new host hook `providers.key_override` in `axf.assistant_host` (skipped for `noKeyOverride` profiles), set by the AI assistant, so the active key replaces an `anthropic` / `claude-code` profile's own key (plugin off = profile keys again). Routes `GET/POST /keys`, `PATCH/DELETE /keys/{id}`, `POST /keys/{id}/test`, `POST /active` (console token, 404 when off, not on MCP). Self-test `test.py` (23). **Token pairs (Oct 25 2026, Opus, 0.2.0):** a subscription token is an access token (sk-ant-oat…) + refresh token (sk-ant-ort…), both required (or Claude Code's `.credentials.json` pasted whole); a pair is authorised only when both work together (access answers or has expired → the refresh grant at Anthropic's OAuth endpoint issues a new one → that one answers), the rotated pair is stored; older single tokens are flagged and can't be active until their refresh token is added (`PATCH /keys/{id} {refresh}`). Pairs renew before expiry (thread every 10 min, 30 min ahead; on read 5 min ahead; failover renews before probing). The active pair is written to Claude Code's `~/.claude/.credentials.json` on the VPS: directly when `AXF_CLAUDE_CREDENTIALS` points at it, else (or when that fails) the trouble goes in the sync log and **Vinny** runs a fixed `vps.run` (approved on axHub) that copies a staged 0600 file out of the console container (`AXF_CONSOLE_CONTAINER`, `AXF_VPS_CLAUDE_HOME`), so no token is ever in a command or approval; routes `GET /vps`, `POST /vps/sync`; the dialog shows the sync log + Approve link.
