## Status (as of Oct 21 2026)

- **Hidden slots (Oct 18 2026, built on Opus):** chrome types are `"hideable": true` in `asset-types.json` (app-menu, toolbar, nav-menu, context-menu; themes, layouts, controls and the policy never). Settings → Appearance → Assets gives those drop-downs a **Hidden** choice (Android: a Hidden chip). Engine `core/engines/hide.ts` = Kotlin `engine/HideEngine.kt`; `compileLayout(l, hidden)` / `LayoutEngine.compile(l, wc, hidden)` drop a hidden region like a refusing slot; a hidden context menu never opens (web: the browser's own menu). Runtime `slotHidden`, `hiddenSlots`, `setSlotHidden`, action `slot.hide:<type>:on|off`, overrides in settings `axf.hide.<type>` (Kotlin KV `<key>:hide`); rolls skip hidden slots, Reset assets un-hides. `SettingSpec.slot` (both ports) names the slot a setting is about: while it's hidden the row greys out and is disabled (Randomize toggles carry it; Assets in rolls greys too). Fixtures `spec/fixtures/hide.json` + `hidden-*` cases in `layout-slots.json` (Kotlin ConformanceTest written without a compiler; check the CI issue).
