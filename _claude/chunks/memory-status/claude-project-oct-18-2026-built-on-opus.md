## Status (as of Oct 21 2026)

- **claude-project (Oct 18 2026, built on Opus):** `framework/cli/claude-project.mjs` (= `axf claude-project`, the `claude-project` shell command and `/claude-project` in any Claude Code session; `deploy/claude-pick.sh --install` installs both globally). Run in any folder: detects the stack and the AXF relation, writes a validated `project.manifest.json` (`x.claudeProject`, `x.port`, `x.remotes`), `_claude/` (with `shared/` copied), `CLAUDE.md` (or adds the rules import to an existing one) and `docs/FIRST_SESSION.md`, commits (new repos get a `.gitignore` and never commit `.env`/key files; existing repos commit only these files), then gives it a home: `github` (creates the repo or uses an empty one, pushes, gives the Claude GitHub app access so it shows in Claude.ai, else prints the link), `vps` (bare remote `/srv/git/<name>.git` + working folder `~/projects/<name>`, locally or over SSH with `--vps-host`), `device`. For a non-AXF app it asks each time: port by `bake` or `rebuild`, or `no`; a port is parked for Fable as pending item `port-<name>` with a plan in the project's `_claude/memory/docs/port-to-axf.md`. Token from `GITHUB_TOKEN`/`gh auth token`, passed to git through the environment only. The engine that runs ports is pending item `app-port-engine` (Fable); turning xGallery's New project wizard into an AXF library that clones an app's install with its current data is pending item `lib-clone` (Fable).
