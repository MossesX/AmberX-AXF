## Status (as of Oct 21 2026)

- **Widget kinds — eleven new attachable widget types (Oct 20 2026, Fable):** `logo` (wordmark / icon / image, size, link), `action-button` (icon and/or label running one action), `label` (text in a tone), `status` (dot + text bound to a runtime counter: on above zero), `counter` (a runtime counter as a number, `99+` past max, hidden at zero), `progress` (bar bound to a counter over max), `avatar` (the bound account's initials, or text / image), `link` (https / http / mailto / tel only; anything else isn't drawn), `theme-switch` (light ↔ dark color theme via `rt.swap`), `spacer` (gap; `flex` pushes what follows to the other end on the web) and `divider`. All `"widget": true` + `"attachable": true` in `asset-types.json`, so they attach to every host (banners, toolbars) and show in Build Pilot's designers by themselves; a host's `attach` block without `types` now takes **every attachable type** (banner), a `widgets` block every widget type (toolbar). Rules live in the widget engine on all ports (`widgets.ts` = Kotlin `WidgetEngine`: `widgetTone`, `counterText`, `statusOn`, `progressPercent`, `avatarInitials`, `linkHref`, `imageSrc`, `spacerUnits`, `logoSize`, `avatarSize`, `progressWidth`, `themeSwitchNext`), pinned by `spec/fixtures/widgets.json` → `kinds` (web `check-widgets.mts` 215 checks; Kotlin `ConformanceTest`, replayed locally through a kotlinc harness). Renderers: React `components/Widgets.tsx` (registry) + CSS `fx-widget-*`; Compose `axf-ui/components/WidgetKinds.kt` (registered in `WidgetRenderers`; image logos/avatars draw their text/initials there since the kernel UI ships no image loader; `flex` spacers are a fixed gap). Starters: one or two per type (`assets/<type>/`), `framework/defaults.json` + every app manifest name one per type (so older apps' active slots stay complete); the console's banner gained a day/night switch next to its clock. Crowded banner sides now clip instead of overlapping on phones (`.fx-banner__side { overflow: hidden }`; labels hide ≤ 480 px). engine-rpc `app-defaults` carries `widgets`, `attachable`, `typeLabels`, `typeIcons`. Kotlin written without Gradle (kotlinc only): check the "CI build errors" issue.
