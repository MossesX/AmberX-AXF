## Status (as of Oct 21 2026)

- **Project wizard console plugin (Oct 18 2026, built on Opus; ported from xGallery's New project wizard):** `apps/console-web/plugins/project-wizard` (`ai.amberx.axf.console.project-wizard`), nav → Plugins → **New project**. Five steps: Source (GitHub repo, VPS repo in `/srv/git`, a folder on the console server inside the allowed roots, or a new AXF app from a template + boilerplate; each with a Browse list) → Details (name, id = hub folder, description, kind, visibility) → Homes (GitHub, VPS git, local git folder: new / existing / skip, checked live: free, empty, has commits, is the source) → Claude project (what gets written; port question for non-AXF code) → Review → run. The engine `wizard.mjs` (`--json` actions status/inspect/check/list/run/kit/link/forget) clones or `axf init`s the working folder, runs `claude-project` (manifest, `_claude/`, CLAUDE.md, FIRST_SESSION, commit, homes, Claude GitHub app access), then writes the **Claude.ai project kit** in `_claude/claude-ai/` (INSTRUCTIONS.md + context/PROJECT, CLAUDE, RULES, DECISIONS, FIRST_SESSION, README) and pushes it to every home. claude.ai has no Projects API: the done screen copies the instructions, downloads the context files, opens claude.ai/projects/new, and saves the project link pasted back into `project.manifest.json` → `x.claudeAi.url`. List of projects made (no secrets) in `.axf-console/project-wizard.json` (0600). Env: `GITHUB_TOKEN`, `AXF_WIZARD_WORKSPACE` (default `~/projects`), `AXF_WIZARD_ROOTS`, `AXF_VPS_HOST`/`AXF_VPS_USER` (SSH) or `AXF_VPS_GIT_DIR` (default `/srv/git`, used when it exists locally). Settings → **Project wizard** shows what's reachable. Guards (after an independent review): never reads or writes through symlinks in a project (also in `claude-project`), folder sources only inside the allowed roots and never a root itself, the console's own checkout or `.axf-console`, never a folder inside another git repo, and a non-git folder with files needs the explicit "Commit everything" opt-in; secret-looking files (`.env*`, keys, `secrets.env`, `credentials.json`, `.axf-console/`) are never committed; existing repos only get the wizard's own files committed (staged work is left alone); repo names can't start with `.`/`-` or contain `..`; the kit never writes the VPS user@host. One writing action at a time (run, kit rebuild, link, forget), and a timeout kills the whole process group. Routes need the console token, 404 when disabled, not on MCP. CI: `test.mjs` (fake GitHub API + bare repos, including every guard). `lib-clone` (Fable) stays parked for the cross-port library and cloning with data.
