## Status (as of Oct 21 2026)

- **Stuck items get a trash can, active ones a timer (Oct 22 2026, Opus):** in the Activity, Build manager and Codebase changes banners an item is **stuck** when its source has gone quiet ("No word": 10 min for a session's build, the report TTL for activity) or it has been active for 30+ minutes; stuck items show a **trash can** that takes them off on every device, and every active or stuck item shows a **running timer** (time since it started; "quiet / no word" time when stuck; warning colour). Activity: `DELETE item` now works for any item (a report is deleted; any other source's item is remembered in `dismissed.json` for a day), and the summary says "N stuck". Codebase changes: `POST entries/{id}/abandon` + `axf.changes@1.abandon(id, by)` finish an entry with no result as failed ("Stalled", unfinished steps skipped) and close it everywhere; it stays in the log. Build manager: `POST abandon {changeId}` goes through that service, so the build leaves Live. **Every stuck build gets its own trash (Oct 22 2026):** the Build manager banner lists every other running build under the first (expanded), each with its own trash can when stuck (trashing the first used to bring the next stuck one up in the same spot); an entry closed in the Codebase changes banner that has gone quiet is no longer live (`liveFromChanges`).
