## Status (as of Oct 21 2026)

- **Context menu designer plugin (Oct 25 2026, Opus):** `apps/console-web/plugins/context-menu-designer` (`ai.amberx.axf.console.context-menu-designer`), nav → Plugins → Context menu designer, right-click → Design this menu…, action `context-menu-designer.open`. Create, edit, name, rename, duplicate, delete and save context menus; **chunks** = reusable pieces (Save as chunk from any menu) inserted into a menu by name, holding items, separators and other chunks (loops and missing chunks reported and skipped, ≤ 6 deep). Every menu and chunk carries its own style (font, size %, weight, style, text / background / hover text / hover background colour: a theme token `token:<name>` or `#rrggbb`); a chunk inherits the surrounding menu's style or uses its own (blank fields fall back to the menu). Floating, draggable live preview re-renders on every change. A saved menu compiles (`web/core.ts` `compile`, `toAsset`) into context-menu asset `ctxd-<id>` (default target = your menu, other targets kept from a base menu) registered at start; styles reach the real menu through one stylesheet keyed on the new `data-axf-item` attribute `MenuList` puts on each item. Server `GET /designs`, `PUT|DELETE /designs/{id}` (console token, 404 when off, not on MCP), data `designs.json` (context-menu-designs@1, 0600). Tests `test.py` (19, runs `test.mts` 28). **0.2.0 (Oct 25 2026, Opus): Actions window, Filter dialog, the app's menus.** The item editor's **Pick…** (and **Actions…** on the entries bar, action `context-menu-designer.actions`) opens the **Actions** floating window (tab kind `ctxd-actions`): every action the app can run, grouped Plugins / Framework / Application › owner, plus ready-made `nav:<page>`, `dialog:<id>`, `settings.open:<tab>`, `swap:<type>:next|previous`; search bar + **Filter** button (badge = choices changed) opening dialog `context-menu-designer.filter` (sources Plugins / Framework / Application with counts, only-these owners, ready-made / needs-arguments / stand-ins / only-my-role switches, sort; one setting `context-menu-designer.actions.filter`, hot). Tapping an action sets the selected item's action (label + icon when blank) or adds a new item. **This app's menus** lists every context-menu asset (each target) and what plugins add per target; **Load into the designer** makes an unsaved copy (optionally with the plugin items, then `contributions: false`); items keep live lists (`provider`). Framework: `ActionMeta.module` + `ActionBus.withModule` (installLibraries, runtime = `axf.framework`), `rt.contextTargets()` (Kotlin deferred, PORTING.md). Pure catalog `web/actions.ts`; tests `test.py` 21, `test.mts` 52. Not screenshot-verified. <!-- axf-plugin:context-menu-designer -->
