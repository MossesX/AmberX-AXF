## Added

- **Engine** `framework/core/engines/appmenu.ts` (pure): `mergeAppMenu`, `compileAppMenu`, `buildAppMenu`,
  `compileProviderItems`, `parseChecked`, `resolveChecked`, `truthy`, `cleanSeparators`, `titleFromId`,
  `chromeToggleTypes`, `chromeToggleItems`, `appMenuSearchEntries`, `validateMenuItems`; constants
  `MENU_MAX_DEPTH`, `PROVIDER_MAX`, `MENU_DEFAULT_ORDER`, `CHECKED_KINDS`, `MENU_ITEM_FIELDS`, `DEFAULT_MENU`
  (`more`), `ASSET_ORIGIN`.
- **Runtime** (`framework/core/runtime.ts`): `AppMenuProvider`, `addAppMenuItems`, `removeAppMenuItems(module|id)`,
  `appMenuContributed`, `registerAppMenuProvider` (returns a remover), `unregisterAppMenuProvider`,
  `appMenuProviderIds`, `appMenu()` (merge cached per active asset; conflicts reported once through
  `rt.diagnostics` as `contribution-conflict`, notes once in the terminal channel `menus`), `loadAppMenuProvider`
  (async), `appMenuSearchEntries`; built-in providers `views`, `nav`, `toolbar`, `settings`, `windows`, `dialogs`,
  `chrome`.
- **Library contract** (`framework/react/library.ts`): `AxfWebLibrary.appMenu`, `AxfWebLibrary.appMenuProviders`,
  installed and removed with the library.
- **Renderer** `framework/react/components/AppMenu.tsx`: `AppMenuDropdown`, `AppMenuList`, `useIsPhone`
  (`APP_MENU_PHONE_QUERY` ≤ 480 px): flyouts on desktop, drill-down panels with a Back row on phones, live lists
  loaded on open (loading / error / empty rows), badges, check marks (`menuitemcheckbox`), shortcuts, keyboard
  (arrows, Home/End, Enter, Escape, Left/Right across menus). CSS in `framework/ui/axf.css` (`.fx-menu__check`,
  `__badge`, `__row`, `__loading`, `__error`, `__empty`, `__spinner`, `__back`, `.fx-dropdown--phone`), tokens only.
- **Fixture** `framework/spec/fixtures/app-menu.json` (generated by `gen-fixtures.mts`; every other fixture
  unchanged) and **checker** `framework/spec/check-app-menu.mts` (113 checks: constants, titles, truthiness, bindings,
  merge, compile per role incl. hide-gating and a depth cap, the real `developer` asset, providers with More…, chrome
  toggles, search entries, validation agreement core = CLI, runtime API end to end). Added to CI (`android.yml`
  node job).
- Catalog feature `k.appmenu` (partial: web built, Android deferred); plan + tracker regenerated.
- Plugin guide (`apps/console-web/plugins/README.md`) documents the hooks.
