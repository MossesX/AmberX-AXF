# Decisions that apply to every project

- **Oct 18 2026:** rules, guidelines, decisions and memory must be active when he works in Claude Code from the mosh terminal on the VPS. First kept in the AmberX-AXF repo (`memory/`), then on axHub (`memory/<git repo name>/`). A later redesign (claude-fs@1, `/Claude`) was undone the same morning.
- **Oct 18 2026 (current, axhub-projects@1, built on Opus):** the axHub container has a `/projects` directory (its own Docker volume) with one schema-structured folder per project built with or for AmberX. Every new and existing project has a manifest (`project.manifest.json`, `project-manifest@1`) defining important information, its repo included (a repo that doesn't exist yet is still defined, for future naming). The hub folder is named after the manifest's `name`. Every hub project folder has `_data/` (the project's shared data, laid out like the project) and `_claude/` with `memory/`, `instructions/`, `rules/` and `shared/`; projects have the same `_claude/` and sync with their hub folder; `shared/` syncs with the hub-wide `/projects/_shared/_claude/`. The build engine never loads or compiles a project without a validated manifest; the manifest's validation rules are defined in the Dev Console's **Standards** section. When a file changed in two places, sync holds it and asks him. axHub decisions #70-#76.
