# Install guides (AmberX framework, axHub, Dev Console)

The full install notes live in the AmberX-AXF repo, because rules and code link to them by path:

- `install_steps.md`: step by step on a new host, from new accounts to the first development session (about 2.5 to 3.5 hours).
  https://github.com/MossesX/AmberX-AXF/blob/main/install_steps.md
- `install_instructions.md`: every key and setting, and why it is needed (section 10: the threads log set-up).
  https://github.com/MossesX/AmberX-AXF/blob/main/install_instructions.md

On the VPS: `/opt/axf/install_steps.md` and `/opt/axf/install_instructions.md`. Other repos keep their own copy
(`/opt/axhub-web`, `/opt/molly`, `/opt/amberx-web`).

Related notes here: `auto-deploy.md` (how each repo deploys from GitHub to the VPS), `../commands/quick-docs.md`
(saved shell commands).
