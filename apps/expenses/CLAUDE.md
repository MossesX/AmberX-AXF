# Expense

The AmberX Expense Tracker as a standalone web app, live at https://expenses.amberxai.com.
It is a Next.js 16 / React 19 / MUI app: a ledger with tabs, grid and tree views, imports,
paydays, reports and a Claude-powered assistant, behind the app's own sign-in (`accounts` module).
It started as the `expenses` module "peeled" out of MossesX/studioX, with the AmberX framework
(`@axf/core` 0.0.25) vendored under `vendor/axf-core`, so this repo builds on its own.

## Build, run, test

From README.md / package.json:

```
npm install
npm run typecheck      # tsc --noEmit — the real type gate
npm run dev            # http://localhost:3200/expenses
npm run build          # next build
npm run start          # next start on :3200
```

- No test suite exists. `next.config.ts` sets `ignoreBuildErrors: true`, so `next build`
  will NOT catch type errors — always run `npm run typecheck`.
- Docker: `docker build -t amberx-expenses .` and `docker compose up -d` (needs Coolify's
  `coolify` Traefik network and the external `amberx-studio-data` volume).
- Deploy: `.github/workflows/deploy.yml` runs on push to `main` (or manually). It SSHes to the
  VPS with a restricted key (secret `VPS_SSH_KEY`) that can only run `ping` and
  `deploy expense`; the real build script is `~/hub/deploy/expense.sh` on the VPS, then it
  checks `https://expenses.amberxai.com/login` returns 200.

## Conventions & decisions

- **Shared data with the studio:** compose mounts the SAME volume as studio.amberxai.com
  (`amberx-studio-data` at `/data`). Ledger, pay schedule, saves/reports vault and accounts are
  one copy across both hosts; sessions are per host. `EXPENSES_DATA_VOLUME` cuts it loose.
- Data root is `AXS_DATA_ROOT` (defaults to `<cwd>/data`, git-ignored). No ledger data or
  credentials in the repo.
- Assistant backends: Claude API (`ANTHROPIC_API_KEY`) or Claude Code CLI with a
  subscription token (`CLAUDE_CODE_OAUTH_TOKEN`); the image installs `@anthropic-ai/claude-code`
  and a source snapshot at `/app/source` for the assistant to read/patch.
- Files marked "generated by peel — do not edit" (e.g. `next.config.ts`, `installed.generated.ts`)
  came from studioX's peel tool. Since this repo is now the source, edit them carefully and say so.
- Work has been done on `ccr-*` branches and merged via PR into `main`; `main` deploys.
- Port 3200 everywhere (dev, start, container).
